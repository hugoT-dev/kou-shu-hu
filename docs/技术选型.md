# 口述护技术选型（Sprint 1）

## 语音识别

默认本地/CI 用 mock。自建保底：**FunASR `paraformer-zh-streaming`（约 220M，CPU 流式）+ `paraformer-zh` 句尾 2pass**。云端仍可用 DashScope `paraformer-realtime-v2`。

| 路径 | 流式 | 部署 | 结论 |
|------|------|------|------|
| FunASR paraformer-zh-streaming | WebSocket 2pass | 服务器 Docker，绑 `127.0.0.1:10095` | **自建默认** |
| DashScope Paraformer-realtime-v2 | 是 | 按秒计费 | 无 GPU 时的云端备选 |
| Fun-ASR-Nano | 是 | 需 GPU 更稳 | 口音更好，后续可换 |

实现：`backend/yl-asr` 的 `StreamingAsrEngine`。`YL_ASR_PROVIDER=mock|funasr|dashscope`。

FunASR **不要对公网开放 10095**。容器只映射 `127.0.0.1:10095`。

- 与 FunASR 同机的 `yl-asr`：`FUNASR_WS_URL=ws://127.0.0.1:10095`，`YL_ASR_PROVIDER=funasr`
- 本机 Java 连远程：`ssh -L 10095:127.0.0.1:10095 USER@39.107.60.241`，再设同样的 `FUNASR_WS_URL`

独立部署目录：`backend/funasr`（`docker compose up -d --build`）。首次会拉 PyTorch CPU 与两个模型，启动可能数分钟。

原始录音与识别文本分开存储：文本可改，原声不可替换。

## 微服务（Spring Cloud + Nacos）

网关与注册中心合一：**唯一 Java 基础设施应用是 `yl-gateway`**（Spring Cloud Gateway + Nacos Discovery）。服务发现由 **Nacos** 承担，不再单独部署 Eureka / `yl-registry`。

| 模块 | 端口 | 职责 |
|------|------|------|
| Nacos（Docker 或本机） | 8848 | 服务发现（可选配置中心） |
| yl-gateway | 8080 | 网关、WebSocket 转发、静态页代理；`lb://yl-asr`、`lb://yl-nursing` |
| yl-asr | 8081 | 流式 ASR，注册到 Nacos |
| yl-nursing | 8082 | 护理记录、原声/影像、交接清单、H5 资源代理，注册到 Nacos |
| yl-common | — | DTO 与规则解析 |

版本对齐：Spring Boot 3.2.12、Spring Cloud 2023.0.3、Spring Cloud Alibaba 2023.0.1.2。

| 点 | 选择 | 原因 |

## 目录

```
docs/              需求、选型、草图、可点击原型（prototype/）
backend/          Spring Cloud 全部 Java 模块；docker-compose 仅 Nacos（本机 Java 联调）
frontend/          Vue H5 Demo（及后续小程序）；Docker 由 nginx 镜像提供，不混入 Java 模块
docker-compose.yml 整栈部署（Nacos + 网关 + ASR + 护理 + H5）
```

## Docker 整栈部署

在仓库根目录：

```text
docker compose up -d --build
```

| 服务 | 容器 / 发现名 | 宿主机端口 |
|------|----------------|------------|
| Nacos | nacos（控制台 8848） | 8848、9848 |
| yl-gateway | yl-gateway | 8080 |
| yl-asr | yl-asr | 不对外 |
| yl-nursing | yl-nursing | 不对外（H2/媒体卷 `/data`） |
| frontend | nginx → 网关 `/api`、`/ws` | 8181 |

容器内 `NACOS_ADDR=nacos:8848`，并以 Docker 主机名作为 `NACOS_DISCOVERY_IP` 注册。Nacos 健康后再起 Java 服务；进程失败会自动重启直到注册成功。

H5 Demo：http://127.0.0.1:8181/ ；网关：http://127.0.0.1:8080/ ；Nacos：http://127.0.0.1:8848/nacos 。本机前端：`cd frontend && npm run dev` → http://127.0.0.1:5181/ 。

DashScope：`YL_ASR_PROVIDER=dashscope DASHSCOPE_API_KEY=... docker compose up -d`。

FunASR 自建（服务器只绑本机 10095）：`backend/funasr` 目录 `docker compose up -d --build`。本机 `yl-asr` 用隧道：

```text
ssh -L 10095:127.0.0.1:10095 USER@39.107.60.241
YL_ASR_PROVIDER=funasr FUNASR_WS_URL=ws://127.0.0.1:10095
```

## 本地验证

```text
cd backend
mvn -q test
```

本机联调：`cd backend && docker compose up -d` 只起 Nacos，再 asr → nursing → gateway。前端 `cd frontend && npm run dev` 打开 `http://127.0.0.1:5181/`，或先 `npm run build` 后打开 `http://localhost:8080/`。
