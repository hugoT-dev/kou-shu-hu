# 口述护 可点击原型

本目录是早期 H5 **界面原型**，只用于评审交互与视觉，**不是**线上前端。

用浏览器直接打开 `start.html` 即可，多数页面不依赖后端。

| 文件 | 说明 |
|------|------|
| `start.html` | 站点图 |
| `caregiver.html` | 护理员端（示意数据为主） |
| `admin.html` | 院长端（示意数据） |
| `asr-demo.html` | FunASR 链路演示（需后端） |

正式前端在仓库 `frontend/`。Sprint 1 第一步是 Demo 联调页，走真实接口测主流程。
