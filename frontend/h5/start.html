口述护 可点击原型

交接班清单 + 护理记录语音录入。用浏览器直接打开本页即可，不是 Axure 工程。

护理员端（核心）

  1. 首页三按钮
  2. 记录：按住说话，文字边说边出 → 播放原声 → 异常可拍照/录像 → 保存
  3. 交接：本班清单可听原声、看影像 → 确认交班
  4. 确认：听原声、看影像 → 逐条已了解 → 完成接班

  2. 护理记录查询与导出
  3. 交接确认率
